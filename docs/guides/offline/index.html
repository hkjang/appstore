AIR-GAPPED INSTALLATION

tar.gz 한 개로 AppStore 서비스를 폐쇄망에 반입하기

릴리스에는 AppStore 서비스 이미지만 포함됩니다. React UI, Go 서버, 마이그레이션과 초기 카탈로그는 이미지 안에 있으며 PostgreSQL은 폐쇄망에서 별도로 준비합니다.

목차포함 범위선행조건반입·검증환경변수서비스 실행Compose최초 설정검증문제 해결

1. 릴리스 포함 범위

포함

  • appstore:vX.Y.Z Linux/AMD64 image
  • React 정적 자산과 SPA fallback
  • Go API, OIDC, SSE와 MCP 서버
  • PostgreSQL migration과 초기 seed
  • 공개 CA와 timezone database

미포함

  • PostgreSQL image와 데이터
  • Keycloak image와 realm
  • AI model 또는 provider image
  • reverse proxy, DNS와 조직 인증서
  • 실제 운영 secret
v2.3.1 파일 규칙: custom asset은 appstore-v2.3.1.tar.gz이고, load 후 image는 appstore:v2.3.1입니다.

2. 선행조건

  • Linux/AMD64 Docker Engine과 서비스 운영 권한
  • 접근 가능한 PostgreSQL database와 schema 변경 권한
  • container에서 PostgreSQL을 찾을 수 있는 내부 DNS·network
  • SSO 사용 시 폐쇄망 Keycloak Issuer와 TLS 신뢰 체계
  • AI 사용 시 폐쇄망 OpenAI-compatible, vLLM, Ollama 또는 Custom endpoint
  • 조직 reverse proxy, HTTPS 인증서와 서비스 FQDN

AppStore는 시작할 때 embedded migration을 PostgreSQL advisory lock 아래 자동 적용합니다.

3. archive 반입과 검증

  1. 온라인 구간에서 custom asset을 받습니다.
    appstore-v2.3.1.tar.gz로 표기됩니다. GitHub의 자동 Source code archive와 혼동하지 않습니다.
  2. 릴리스 본문의 SHA-256과 비교합니다.
    sha256sum appstore-v2.3.1.tar.gz
  3. 승인된 매체로 폐쇄망에 반입합니다.
    조직의 악성코드 검사, 반입 결재와 매체 폐기 정책을 따릅니다.
  4. gzip과 Docker manifest를 확인하고 load합니다.
    gzip -t appstore-v2.3.1.tar.gz
gzip -dc appstore-v2.3.1.tar.gz | docker load
docker image inspect appstore:v2.3.1 \
  --format '{{.RepoTags}} user={{.Config.User}} version={{index .Config.Labels "org.opencontainers.image.version"}}'

검사 결과에는 appstore:v2.3.1, non-root 사용자 appstore:appstore, 동일한 OCI version label이 보여야 합니다.

4. 네 환경변수 준비

예제 파일을 복사하고 권한을 제한합니다. 다음 네 이름 외의 서비스 설정은 환경변수로 전달하지 않습니다.

install -m 600 .env.example appstore.env
openssl rand -base64 32

# appstore.env
POSTGRES_DSN=postgres://appstore:ENCODED_PASSWORD@postgres.internal:5432/appstore?sslmode=require
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=replace-with-a-long-random-password
ENCRYPTION_KEY=replace-with-the-generated-32-byte-base64-value
이름용도검증
POSTGRES_DSN유일한 영속 database 연결password 특수문자는 URL encode, TLS 권장
BOOTSTRAP_ADMIN최초·복구 관리자 식별자공유 계정 금지
BOOTSTRAP_ADMIN_PASSWORDBootstrap 로그인 원문최소 12자, 장기 random 값
ENCRYPTION_KEYOIDC·AI 등 DB secret 암호화32 raw byte/64 hex/base64 32 byte
보관: env 파일은 image나 source에 넣지 말고 host 관리자만 읽게 합니다. ENCRYPTION_KEY는 database backup과 다른 승인 저장소에도 복구 사본을 보관합니다.

5. Docker로 실행

docker run -d \
  --name appstore \
  --restart unless-stopped \
  --read-only \
  --tmpfs /tmp:size=64m,mode=1777 \
  --cap-drop ALL \
  --security-opt no-new-privileges:true \
  --env-file ./appstore.env \
  -p 127.0.0.1:8080:8080 \
  appstore:v2.3.1

외부 공개가 필요하면 reverse proxy가 127.0.0.1:8080에 연결하도록 구성합니다. Go 서버의 내부 listen port는 8080으로 고정됩니다.

docker logs --tail 100 appstore
curl --fail http://127.0.0.1:8080/health/live
curl --fail http://127.0.0.1:8080/health/ready
curl --fail http://127.0.0.1:8080/api/version

/health/live는 process 응답, /health/ready는 database와 migration 준비 상태입니다. load balancer는 ready endpoint를 사용합니다.

6. Docker Compose로 실행

docker-compose.yml은 PostgreSQL을 번들하지 않고 외부 DSN을 사용합니다. APPSTORE_VERSION은 Compose가 image tag를 고르는 host-side 치환 값이며 application container에는 전달되지 않습니다.

cp .env.example .env
chmod 600 .env
APPSTORE_VERSION=v2.3.1 docker compose up -d --no-build
docker compose ps
docker compose logs --tail 100 appstore

--no-build는 registry나 build dependency를 찾지 않고 이미 load한 image만 사용하도록 보장합니다. Application 환경에는 승인된 네 값만 전달됩니다.

7. 최초 관리자 설정

  1. 서비스 로그인 화면에서 Bootstrap 계정으로 로그인합니다.
  2. Admin → Settings에서 사이트 이름과 사용자에게 표시할 서비스 URL을 저장합니다.
  3. Admin → Authentication에서 Keycloak Issuer, Client ID와 Secret을 입력하고 연결 시험을 실행합니다.
  4. role/group mapping 후 별도 SSO 관리자 계정으로 /admin 접근을 시험합니다.
  5. Workflow 기본값 OFF, API·MCP 익명 정책과 Key 수명주기를 확인합니다.
  6. AI를 사용할 때만 내부 Provider와 모델 limit을 추가합니다.

8. 오프라인 Acceptance 점검

  • 외부 인터넷 route를 차단해도 /, /apps와 상세 화면 자산이 깨지지 않습니다.
  • /admin/users 직접 접근과 새로고침이 같은 화면을 반환합니다.
  • 익명 사용자는 관리자 API에 접근할 수 없고 일반 사용자는 403을 받습니다.
  • OIDC discovery는 폐쇄망 Keycloak으로만 요청되고 Secret은 재조회되지 않습니다.
  • AI streaming 중 browser를 닫으면 upstream 요청이 취소됩니다.
  • 262144 token 값 저장과 provider/model limit 적용을 확인합니다.
  • 로그인과 profile menu의 version이 image tag와 일치합니다.

9. 문제 해결

증상원인·조치
Container 즉시 종료누락 env, password 길이, ENCRYPTION_KEY 형식 확인
ready만 실패PostgreSQL DNS, port, TLS, 권한과 migration 확인
SSO discovery 실패Issuer realm 경로, 내부 DNS, 인증서 chain과 egress 확인
새 route가 404reverse proxy가 모든 비-API route를 Go 서버에 전달하는지 확인
Secret 복호화 실패backup과 짝을 이루는 원래 ENCRYPTION_KEY인지 확인

지원 요청에는 version endpoint, 발생 시각, Request ID와 redacted log를 포함합니다. DSN, password, token과 Secret은 제외합니다.
